# Minanam 資料庫欄位說明

## SiteSettings
網站全站設定。修改後首頁會自動使用新的學校名稱、目前學年度／學期與首頁文字。

## ThemeCourses
每一週一列。`course_id` 建議固定為 `115-1-W01` 格式，發布後不要修改。

- `school_year`：學年度
- `semester`：1 或 2
- `week_no`：週次
- `youtube_id`：只放 YouTube ID
- `game_url`：遊戲完整網址
- `worksheet_url`：學習單完整網址
- `cover_image`：封面圖片 HTTPS 網址
- `keywords`：額外搜尋關鍵字
- `status`：`published` 或 `draft`

## ThemeSentences
一個課程可有多筆句型，以 `course_id` 對應。`sort_order` 控制顯示順序。

## ThemeVocabulary
一個課程可有多筆單字，以 `course_id` 對應。每筆可放音檔和圖片。

## Storybooks
每一本繪本一列。`book_id` 建議固定為 `115-1-B01` 格式。

## StorySentences
一個繪本可有多筆句型，支援句型音檔、句型說明、例句與例句音檔。

## StoryVocabulary
一個繪本可有多筆單字，支援單字音檔、圖片、說明、例句與例句音檔。

## 搜尋
首頁搜尋會把標題、摘要、關鍵字、句型、句型中文、單字、單字中文、繪本說明與例句納入搜尋。
